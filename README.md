# Fox University Website 

A university website landing page built using HTML and CSS as part of my front-end development practice.

## About the Project

This project is a front-end recreation of a university website design. It includes sections for university information, courses, certified teachers, testimonials, blogs, a request-a-quote form, and contact information.

## Features

- University landing page
- Navigation bar with search
- Hero section
- University services and facilities
- Courses section
- Certified teachers section
- Request a quote form
- Blog section
- Student testimonial section
- Footer with contact information

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## What I Practiced

- Structuring a complete webpage using HTML
- CSS Grid and Flexbox
- Website layout and spacing
- Background images and overlays
- Styling forms and buttons
- Using Google Fonts
- Using Font Awesome icons
